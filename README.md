# Projeto: Apoio a Mães Solo que Trabalham e Estudam

Este projeto nasceu da minha própria experiência como mãe solo que trabalha, estuda e cuida dos filhos ao mesmo tempo. A rotina é cheia de responsabilidades, cobrança e muito pouco tempo, e muitas vezes a sensação é de sobrecarga constante.

A proposta deste projeto é criar uma ferramenta simples, prática e acessível que ajude outras mães a organizarem melhor a rotina, diminuírem a carga mental e terem uma visão mais clara do que realmente importa ao longo do dia ou da semana.

---

## 🎯 Objetivo do Projeto

Desenvolver uma solução que permita:

- organizar estudos, trabalho e compromissos dos filhos;
- visualizar a semana de forma clara e simples;
- registrar metas realistas e acompanhar a evolução;
- organizar o mês financeiramente;
- reduzir a ansiedade e o sentimento de descontrole da rotina.

---

## 👩‍👧‍👦 Público Beneficiado

Mães solo — ou qualquer pessoa com rotina intensa — que precisam de apoio para criar constância nos estudos, no trabalho e nos cuidados com os filhos, buscando mais equilíbrio e clareza na vida diária.

---

## 🧩 Funcionalidades Iniciais

- Registro de tarefas e prioridades  
- Organização semanal  
- Agenda dos filhos  
- Planejamento financeiro básico  
- Geração de relatórios simples usando Python  

*(Novas funcionalidades serão adicionadas conforme o projeto evoluir.)*

---

## 🛠 Tecnologias Utilizadas

- **Python**
- **Pandas** para organização de dados  
- **Matplotlib** para gráficos simples  
- *(Futuramente)* **Streamlit** para interface visual
